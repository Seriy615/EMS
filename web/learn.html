Первая программа на EMS

Программа состоит из контрактов. У контракта есть имя, типизированные входы и результат. Его реализацию можно записать текстом или собрать из контрактов на холсте.

1. Создайте и запустите сумму

В редакторе задайте входам a и b значения 2 и 3, затем нажмите «Запустить». Получится 5. «Файл → Код EMS» открывает текст этого же графа; «Применить к графу» проверяет изменения и переносит их на холст.

@Main(a:Number,b:Number)->Number graph {
    @core::add #sum {
        a <= input::a;
        b <= input::b;
    }
    @std::program::Result #result { value <= #sum; }
    + #sum;
    #sum.next ~> #result.enter;
}

@Main объявляет контракт. @core::add #sum создаёт узел сложения с именем sum. input::a — вход программы. <= соединяет выход значения со входом; b: 3; вместо b <= input::b; задаёт константу.

+ #sum выбирает точку входа. ~> соединяет порты активации: после сложения активируется результат. На холсте это фиолетовые порты; синие передают значения. Поиск работает по русским названиям и по техническим ID. core::add в коде и «Сложение» в библиотеке — один контракт.

2. Условие, переменная и повторение

Для условия добавьте «Больше», «Меньше» или другой контракт сравнения. Его логический результат соедините со входом «Условие» контракта «Условие». Выходы «Да» и «Нет» соединяются непосредственно со входами нужных контрактов.

«Переменная» хранит значение. Вход значения получает новое число, текст или массив; запись происходит при активации переменной. Её выход возвращает текущее значение. Начальное значение задаётся в свойствах. Несколько вызовов одной переменной доступны в библиотеке после её создания. Между отдельными запусками локальная переменная начинается заново; данные UI принадлежат экземпляру контракта и сохраняются между его событиями.

«Начало итерации» и «Конец итерации» передают активацию, без значения. Соедините «Возврат» конца со входом начала. Проверка перед телом или после него определяет вид цикла. Посмотрите оба варианта в лабораторной.

3. Текст без ручного описания узлов

@SumPositive(values:NumberArray)->Number {
    let mut total = 0;
    for value in values {
        if value > 0 { total = total + value; }
    }
    return total;
}

Это тоже EMS: let mut задаёт изменяемое хранилище, if, while и for … in описывают вычисление через общую семантику. Обычный текстовый блок и тело graph компилируются в общий IR. В редакторе графа применяется форма graph; полный код контрактного модуля доступен в его «Код EMS».

Приложение с вводом ε, четырьмя способами расчёта, всеми членами ряда и суммой. Откройте копию: появится окно «Запуск и отладка». Задайте ε и выберите способ. В проекте доступны исходный EMS, реализации контрактов и экспорт самостоятельного приложения.

For и While записаны текстом; Repeat–until и GoTo выражены графами с постусловием и обратным переходом. Отдельных текстовых ключевых слов repeat/goto в текущем профиле нет.
