Состояние и операции

Выберите экземпляр. Операции и инварианты редактируются в обычном графе контрактов.

Экземпляры

Исходный EMS

Исходник сохранён как архив. Применение текста заменит текущий модуль и его графы. Для изменения логики открывайте граф операции.

Начальные данные

Переменные сохраняют значение между вызовами. Начальные данные применяются при новом запуске. В графе используйте контракты чтения и записи этой переменной.

＋ Поле состояния

Поле добавляется в определение контракта и появляется у всех его экземпляров. Их значения хранятся независимо.

Операции

＋ Новая операция

Инварианты

Проверяются у всех экземпляров после операции. Если условие нарушено, изменения откатываются. Граф проверки общий для определения контракта.

Запуск

Кнопка «Выполнить» сохраняет состояние между вызовами. Изменение программы начинает новый сеанс.

Выберите операцию и выполните её.
