# Поля состояния native контрактов в Studio

Статус: AC-129, статические модули `ems-instance-module/1` и документы
`ems-instance-project/1` / `/2`. Это изменение определения контракта в существующей
модели, а не отдельная сущность «данные» или новый интерпретатор.

В документе контрактного модуля выберите экземпляр. «Поле состояния» добавляет
типизированное поле с начальным значением всем экземплярам его определения.
Поля имеют независимое состояние: изменение начального значения выбранного
экземпляра создаёт его override. Значения применяются при создании следующего
runtime owner; изменение программы закрывает прежний сеанс.

На строке поля можно изменить имя или удалить поле. Переименование сохраняет
initial overrides, настоящие read/write контракты во всех операциях, вызовы в
сохранённых вспомогательных графах, интерфейсы/тела инвариантов и UI bindings.
Позиции и описания узлов остаются прежними. Архив исходного EMS сохраняется
дословно: он не выдаётся за актуальный обратный текст всей программы.

Для изменения значения во время исполнения откройте граф операции. В каталоге
есть «Прочитать экземпляр.поле» и «Записать экземпляр.поле». У записи обычный
типизированный вход значения и выход результата; последовательность определяется
явными портами исполнения. Новая операция может читать поле, вычислять новое
значение и записывать его. UI событие ссылается на эту же операцию, а свойство UI
может ссылаться на это же поле. Отдельных копий реализации обработчика нет.

Удаление поля требует отсутствия ссылок из IR, инвариантов, UI и сохранённых
графов, включая пока не вызываемые определения. Редактор перечисляет до 256
зависимостей и даёт ссылки на операцию, точный узел вспомогательного графа,
инвариант или элемент UI. Удаление поля не удаляет связанные узлы и не перестраивает
связи. После явного исправления зависимостей поле можно удалить. Обычное удаление
узлов в графе по-прежнему разрешено; незавершённая схема хранится как черновик.

Изменения документа поддерживают отмену/повтор в текущем окне (до 20 состояний,
суммарно до 8 Mi UTF-16 code units). Сохранение проверяет текущую версию документа;
устаревшее окно не заменяет результат другого окна. Workspace siblings сохраняются.
История не является долговременным журналом версий после перезагрузки.

## Общая семантика и границы

API `src/studio/instance-fields.mjs` предоставляет `addInstanceField`,
`renameInstanceField`, `removeInstanceField`, `instanceFieldDependencies`.
Все изменения возвращают проверенную копию документа; отказ оставляет оригинал.
Добавление/сохранение не исполняют пользовательские initializers или инварианты.
Типы и значения проверяют существующие конечные типы/IR/linker.

Интерфейс инварианта содержит все поля определения. Изменение его интерфейса
сохраняет порядок прежних параметров и позиционные вызовы. При конфликте с
локальным именем или рекурсивными вызовами прежняя реализация остаётся за
гигиенической обёрткой в том же IR. Неиспользуемый параметр не создаёт искусственную
зависимость от поля. Сохранённые графы обновляются как графы с прежней геометрией.
Рекурсия и обёртки используют общие ограничения work/depth runtime/compiler.

Смена типа уже используемого поля, структура экземпляров/определений из форм,
динамическое создание и срок жизни экземпляров, долговременное состояние и полный
обратный native body source остаются дальнейшими задачами. Прямое удаление
используемого определения и переподключение чужих графов не выполняются.

Проверки: `tests/instance-fields.test.mjs`, `tests/browser/instance-fields.test.mjs`.

## Воспроизводимый пример

Импортируйте `examples/native-ui.ems`. В модуле добавьте поле `total: Number`
с начальным `0`, затем операцию `Accumulate(delta: Number) -> Number`.
В её обычном графе соедините чтение `left.total` и `delta` со сложением,
его результат — со входом записи `left.total`, выход записи — с результатом.
Фиолетовые порты соединяются чтение → сложение → запись → результат;
чтение выберите началом операции. Сохраните модуль. Два вызова с `delta=2`
дают `2`, затем `4` в одном сеансе.

В конструкторе UI выберите кнопку `up`, назначьте событию операцию
`left::Accumulate` с `delta=3`. Для текста `count` выберите источник
«Число → текст» и поле `left.total`. При новом запуске текст равен `0`,
после нажатия — `3`. Эти шаги исполняет браузерная проверка AC-129 через
настоящие формы, порты и Worker, с повторным открытием сохранённого проекта.
