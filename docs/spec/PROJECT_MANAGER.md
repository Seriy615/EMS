# Единый локальный каталог проектов — AC-062

Страница `/web/projects.html` объединяет графовые/текстовые и UI/event проекты в одном каталоге. Ссылки «Проекты» доступны из обоих редакторов. Можно создать пустой граф или UI, загрузить счётчик, переименовать, скопировать, удалить, экспортировать и импортировать проект. Счётчик — настоящая source-owned программа EMS, не отдельная JS-логика.

## Модель хранения и проверки

`src/studio/manager.mjs` предоставляет `ProjectManager(storage)`: `list`, `load`, `save`, `copy`, `rename`, `remove`, `export`, `import`. Единственная запись `ems.studio.manager.v1` имеет schema `ems-project-catalog/1`, массив проектов, лимит 50 записей и 8 MiB (длина JS строки). Каждая запись содержит `id`, `name`, `kind`, `source`, `draft`. ID каталога отдельно от UI application/contract ID. Графовый ID и имя совпадают с вложенным графовым проектом; UI source сохраняется без изменения внутренних ID.

`source` — существующий сериализованный `ems-studio-project/1..3` или `ems-ui-project/1..2`. Каждый read/import/save проверяет исходник существующими кодеками: IR, транзитивные контракты/версии, граф, sidecar, UI типы и source→IR witness. Используется установленная core registry. Отсутствующие внешние реализации отвергаются; импорт не выполняет обработчики и не загружает плагины. Никаких новых IR или evaluator не вводится.

Графовый `draft` — null либо `ems-studio-text/1`. Структура и размеры проверены существующим `validateStoredDraft`; незавершённый или синтаксически неверный текст допустим как **черновик**. Его сохранение не применяет текст к графу и не утверждает корректность кандидата. Execute/Apply используют прежний frontend, policy checks и runtime. UI EMS-исходники уже включены в typed UI project; отдельный draft для него запрещён.

До единственного `setItem` проверяются полный кандидат и существующий каталог. Некорректный импорт, несовпадающая identity, повреждённый каталог или отказ квоты не перезаписывают предыдущую запись. При повреждении нет автоматического сброса. Это локальное браузерное хранилище, а не серверная синхронизация, резервное копирование или совместное редактирование. Несколько вкладок используют последнее успешное сохранение; conflict/revision management ещё не реализован.

## Редакторы и транспорт

`/?project=<id>` открывает управляемый граф; `/web/ui-demo.html?project=<id>` — управляемую UI-программу. Графовый редактор сохраняет принятые изменения и текстовый черновик в одной записи проекта. UI сохраняет принятые изменения после успешного перезапуска проверенного Worker preview, включая Undo/Redo. Запускаемое состояние не сохраняется как initial state: повторное открытие запускает сохранённую программу с её начальными значениями. Не применённые UI textarea-кандидаты не autosave.

Ошибка записи отображается редактором; принятая программа остаётся в памяти, предыдущие сохранённые bytes остаются в storage. Квота не означает сохранение. Каталог не сохраняет runtime snapshots, очередь событий, history/Undo между перезагрузками или выбранный узел.

Экспорт каталога — `ems-project-bundle/1` с одной проверенной записью и черновиком. Импорт всегда создаёт свежий ID, никогда не перезаписывает ранее сохранённый проект. При импорте графа меняется только project ID, внутренние contract IDs остаются прежними. Принимаются также старые графовые/UI JSON exports; графовые черновики в этих форматах отсутствуют. Отдельные кнопки JSON/standalone export редакторов сохраняют существующие форматы.

Старые записи `ems.studio.projects.v1`, `ems.studio.ui.v1`, `ems.studio.text.*` остаются доступны на страницах без query project. Они не мигрируются и не удаляются автоматически. Для переноса в каталог экспортируйте старый проект и импортируйте его копию. Старый текстовый draft переносится отдельно вручную; bundle нового каталога включает его сразу.

## Приёмка и дальнейшая работа

Node tests проверяют typed graph/UI witnesses, signed zero, незавершённый draft, copy/rename/import originals, старые JSON, invalid source/types/identity/schema/corruption/quota preservation. Actual Chromium проверяет UI кнопки создания/копирования/переименования/импорта файла, catalog links, graph text Run=12, применение к графу и повторный graph Run=12 после refresh, восстановление draft, изменённый UI source Run=4 после открытия/перезагрузки, сохранность второго проекта.

Это единый рабочий каталог с открытием существующих редакторов. Единое многопанельное окно, project-wide control authoring, graph debugger/source trace, полная визуальная parity, серверная синхронизация и production deployment остаются открытыми. AC-062 не закрывает full AC-012/AC-014 или весь WEB IDE MVP.
