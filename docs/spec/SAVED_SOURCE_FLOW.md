# Сохранённый исходник в обычном редакторе контрактов — AC-119

Статус: reference slice EMS-043/044, G-02/03/14. Полная двусторонняя
проекция языка и составных контрактов остаётся открытой задачей.

## Открытие и редактирование

Ссылка `/?project=...` для сохранённого текстового документа проверяет его
реальный источник и данные запуска. Поддерживаемый finite control IR2
открывается в `/web/flow.html?project=...&source=1`, включая `file` в рабочем
пространстве. Это тот же редактор, каталог, typed ports и compiler/runtime,
что используются новыми графами и обработчиками UI. Нет отдельных блоков
ветвей или автоматических связей при редактировании.

Поддержка определяется действительной проверкой `sourceContractFlow`, затем
компиляцией в обычном registry. Текущие границы AC-117 сохраняются: mutable
locals, if/while/for, break/continue, short circuit, конечные типы. Неподдерживаемый индексный error ABI, дополнительные политики и другие профили
не подменяются приближённой программой. Такой документ остаётся в прежнем
редакторе. Явный `/web/index.html?project=...&file=...` всегда позволяет открыть
исходный текст; legacy проекты без source draft тоже сохраняют прежний вход.

Открытие не пишет в хранилище. Входы берутся из сохранённого draft.inputs,
проверяются по сигнатуре; значения по умолчанию не заменяют неверные аргументы.
Обычные изменения, удаления, перемещения, undo и неполные соединения сохраняются
в отдельном локальном черновике, привязанном к точной версии исходного record.
Run исполняет текущий граф через настоящий Worker; JS и SVG экспортируются
действующими компиляторами. Неполная схема не исполняется и не сохраняется как
готовый документ.

## Явное сохранение

«Сохранить граф» проверяет complete wiring и компиляцию без временного source
registry, затем создаёт самостоятельный flow-документ рядом с исходником.
Для отдельного проекта одна запись каталога превращается в рабочее пространство
с `source.ems.json` и `main.graph.json`. Исходный record, включая текст, inputs,
IR и canvas, сохраняется целиком. В существующем workspace добавляется sibling
файл; его текущие соседи сохраняются. Свободный ID подбирается без перезаписи
одноимённого документа. После сохранения открывается созданный граф.

Черновик исходника и граф — самостоятельные документы: правки графа не обещают
обратного восстановления исходного текста. Workspace export/import переносит
оба документа. [AC-121](FLOW_COMPOSITES.md) сохраняет finite source helpers отдельными
редактируемыми definitions и обычными calls; они не скрываются за атомами и не
разворачиваются молча на один холст. Рекурсия и full inverse остаются отдельной работой.

Если исходный record изменён/удалён в другом окне, сохранение отклоняется до
записи. Локальный черновик остаётся. При повторном открытии изменённого источника
показывается его свежая проекция и уведомление; старый черновик архивируется
отдельно перед следующей записью. Это локальные черновики, не синхронизация.

## Проверки

`tests/source-flow-session.test.mjs`: read-only routing, actual loop result8,
edit4/reopen, independent JS4, перенос обоих файлов через export/import,
CAS/incomplete refusal, коллизии и сохранность соседей, unsupported refusal.
`tests/browser/source-flow-entry.test.mjs`: оба реальных входа (standalone и
workspace), мобильный viewport, Worker8→4, сохранение/повторное открытие и
возврат в исходный текст. Полный профиль языка и глобальная цель не завершены.
