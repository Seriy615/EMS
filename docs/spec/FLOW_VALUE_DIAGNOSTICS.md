# Неинициализированное значение на схеме — AC-120

По сообщению владельца: `UNINITIALIZED_FLOW_VALUE` показывал английский текст
без имени проблемного источника и получателя. Ошибка оставалась практически
неисправимой из интерфейса, особенно на уменьшенной схеме с циклом.

Проверка доступности результата сохранена: data wire не исполняет источник.
Например, результат операции внутри цикла нельзя читать после цикла, если тот
может выполнить ноль итераций. Для накопленного результата используется output
Variable, который имеет initial и обновляется через write input. Runtime не
подставляет вместо невыполненной операции выдуманный результат и не перестраивает
схему автоматически.

Flow validation теперь возвращает точный input port вместе с node/producer.
Это диагностические metadata, не изменение semantic IR или схемы графа.
Клиент связывает ошибку только с действительной текущей ссылкой аргумента. Если
диагностика устарела, она не подсвечивает другой контракт с похожим именем.

На экране показываются русское объяснение с названиями/ID, подсветка обоих
контрактов и проблемного input port, кнопки «Показать источник» / «Показать
получателя». Явный переход центрирует нужный блок и делает scale не меньше0.75,
сохраняя позиции и провода. На мобильном закрывается result sheet, открывая
холст; browser fullscreen не вызывается. Успешная правка и новый запуск очищают
подсветку. Рядом объясняется различие data/activation и запись результата цикла
в переменную. В этой диагностике убраны дублирующие «Выполнение остановлено»,
пустая трасса и «Соединение отменено», чтобы действия помещались в result panel.

Проверки: `tests/flow-diagnostic.test.mjs` — точные node/producer/port, неизменный
граф, устаревшие ссылки. `tests/browser/flow-diagnostic.test.mjs` — actual Worker
array-loop error, фокус при scale0.25→0.75, неизменные positions/connections;
явная смена result data wire на output Variable даёт [1,1,1] и [] при limit0.
Исходный файл графа со скриншота не предоставлен; не заявляется исправление его
конкретных пользовательских соединений. Составные flow definitions — отдельная
незавершённая задача, текущий WIP сохранён отдельно до публикации этого исправления.

## Повторный screenshot: версия открытой вкладки

При старой закешированной версии пользователь может продолжать видеть английскую
ошибку без диагностических действий, хотя сервер уже обновлён. Редактор проверяет
серверную версию при открытии, возвращении во вкладку и восстановлении сети.
Он предлагает явное обновление как при ожидающем Service Worker, так и когда
другая вкладка уже активировала новый Worker, а документы этой вкладки ещё старые.
Автоматической перезагрузки, изменения графа или очистки localStorage нет.
Офлайн-ошибка проверки не прерывает редактирование. При применении повторно
проверяется соответствие Worker актуальной серверной версии.

Это исправляет обнаружение устаревшего редактора, а не пользовательские связи.
Для точного воспроизведения повторного screenshot запрошен экспорт его графа;
до получения файла его причина и исправление не объявляются установленными.
