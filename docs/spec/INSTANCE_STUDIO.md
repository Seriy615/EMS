# Контрактный модуль в Studio — AC-126

Статус: срез EMS-038; ядро static instances AC-125. Глобальная цель EMS остаётся активной.

## Документ и представления

`kind: contract` в существующем каталоге и многофайловом workspace открывает `/web/contracts.html`. Главная создаёт пустой модуль с `main::Run` и результатом 0; пример счётчика не навязывается. Импорт поддерживает native `.ems`, `ems-instance-module/1`, `ems-instance-project/1` и обычный bundle. Импорт, список и сохранение проверяют типы/IR, но не исполняют initializer, invariant или transition.

Обзор показывает экземпляры, typed начальные данные, операции и инварианты. Начальные данные редактируются отдельно для экземпляра и применяются к следующему сеансу. Вычисляемый initializer не подменяется вычисленным/фиктивным значением при открытии: форма сообщает, что он вычисляется из EMS, и позволяет явно заменить его литералом. Массивы, словари и tagged values вводятся в общей finite JSON модели; String — обычный текст.

Операция и инвариант открываются в **том же `/web/flow.html`**, с обычными портами, контрактами каталога, перетаскиванием, ручными связями, переменными и undo. У переходов доступны настоящие `state.read/write` bindings с понятными именами `left.value`. Общий граф сохраняет все операции, вспомогательные определения и геометрию; выбор операции меняет область просмотра. Новый typed transition создаёт операцию у всех экземпляров определения и открывает её обычный Result-контракт для дальнейшего редактирования. Новый инвариант начинает с Boolean true и входов полей определения; его следует заменить нужным условием в графе.

## Хранение и согласованность

Закрытый authoring envelope `ems-instance-project/1` содержит:

- `module`: версионированный semantic `ems-instance-module/1`;
- `sourceArchive`: исходный native EMS или null, **архив**, не обещание полного обратного преобразования графа в текст;
- `bodyGraph`: общий ordinary FlowProject или null до первой графовой правки;
- `invariantGraphs`: `{contract,id,flow}` для отредактированных pure-проверок.

Максимум документа — 4 MiB UTF-8, модуля — 1 MiB; лимиты каталога и графов сохраняются. При импорте/сохранении граф повторно компилируется и должен совпасть с semantic module. Геометрия не становится семантикой. Сохранённый bodyGraph используется непосредственно: dispatcher IR после графовой компиляции не проецируется повторно в искусственную структуру.

Неполный graph draft хранится отдельно с точной исходной версией документа. Удаление блока разрешено и не переписывает действующий module; «Сохранить модуль» требует полного корректного кандидата и сохраняет все области одним действием. Сохранение из устаревшего окна отклоняется `STALE_INSTANCE_PROJECT`, черновик остаётся. Черновик от прежней версии при последующей записи переносится в `.previous`. Соседние файлы workspace сохраняются.

## Исполнение и экспорт

Обзор и canvas запускают actual persistent Worker owner ядра AC-125. Последовательные операции в одном владельце видят собственные предыдущие записи и остальные экземпляры. Изменение semantic программы начинает новый сеанс, pan/zoom и следующий вызов с другими аргументами сами по себе состояние не сбрасывают. «Остановить» завершает владельца; перезагрузка начинает с initial. На canvas helper не выдаётся за публичный transition: запуск требует выбрать операцию модуля.

Внешние invariant boundaries не являются удаляемыми блоками bodyGraph. После изменения перехода те же инварианты исполняются runtime/linker; нарушение откатывает память и показывает сохранённое состояние и ссылку на граф нарушенного инварианта. Отдельный запуск pure-графа инварианта допускает Boolean false как результат проверки. Скачать приложение из обзора или любой области графа — независимый ESM **всего модуля**, с фабрикой `createSession`, а не вырезанный body без guards. Экспорт документа сохраняет весь authoring envelope. «EMS IR» показывает актуальный semantic module. Применение архивного/отредактированного native EMS явно заменяет модуль и графы.

## Приёмка и ограничения

Node: каталог/import/raw source/IR/bundle/workspace; invalid initial импортируется без исполнения и отказывается при createSession; typed operation/invariant edits, shared scopes, geometry, incomplete deletion/draft, CAS/siblings, witness mismatch, signed zero и Map. Chromium: реальные формы/порты/мобильный canvas, повторный Worker-вызов, reload, actual скачанный ESM в отдельном Node process, invariant rollback/link, новый transition без текстового кода, initial/instance identity, offline reload и запуск.

Это не завершение EMS-038. Проекция ограничена текущим `sourceContractFlow`-профилем; приёмка не объявляет визуально редактируемыми все допустимые конструкции control IR. Создание новых определений/полей/экземпляров пока через явное применение native EMS; графовый редактор меняет тела и pure инварианты, обзор добавляет операции/инварианты и initial overrides. Изменение публичной сигнатуры в canvas не меняет объявленный интерфейс: применение откажет при несовпадении. Нет нового cross-file import/linker, durable persistence, dynamic instance reference/lifetime, native instance→UI event/observation binding или полного text/graph inverse. Старые UI-проекты сохраняют проверенный reactor-путь; объединение с native instance document — следующий отдельный срез.
