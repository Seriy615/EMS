# ЛР № 2 · вариант 6 на EMS

Открытие: главная страница → «Лабораторная № 2 · вариант 6». Создаётся
редактируемая копия настоящего контрактного проекта и открывается UI-конструктор
с работающим приложением. Введите положительное ε и выберите способ. Полный
исходник доступен через «Код приложения EMS»; реализации доступны в общем
контрактном редакторе. Исходник: `examples/lab6.ems`; проверенная копия проекта:
`examples/lab6.ems-project.json`. Это один UI с четырьмя настоящими переходами
экземпляра Series, без JS-обработчиков прикладной логики.

Условие с фотографии: aₙ = 1/2ⁿ + 1/3ⁿ. Принято n ≥ 1. Выводятся все aₙ > ε
и их сумма. ε ограничивает размер включаемого члена, а не гарантирует абсолютную
ошибку суммы меньше ε. При ε = 0.001 включены n=1…9, сумма равна
1.4980214723682874; бесконечная сумма равна 1.5. При ε ≥ 5/6 список пуст, сумма 0.

Пусть qₙ=(2/3)ⁿ. Тогда aₙ=2⁻ⁿ(1+qₙ), поэтому

    aₙ₊₁ = aₙ · (1 + (2/3)qₙ) / (2(1+qₙ))
    qₙ₊₁ = (2/3)qₙ
    a₁ = 1/2 + 1/3, q₁ = 2/3.

`lab.Next` вычисляет следующий член именно из текущего. Все способы используют
эту рекуррентную формулу. Числа — обычный EMS Number/binary64, с округлением.

- `lab.While`: текстовый `while`, проверка перед включением члена.
- `lab.For`: настоящий `for … in`, два конечных вложенных перебора 17×64
  позиций с выходом по ε. 1088 позиций достаточно для положительных binary64:
  после 1075 делений пополам компонент 2⁻ⁿ обнуляется; 3⁻ⁿ убывает быстрее.
  Два небольших массива заменяют огромный литерал из 1075 чисел и сохраняют
  конечную страховочную границу независимо от пользовательского ε.
- `lab.RepeatUntil`: обычный контрактный граф с проверкой выхода после тела.
  Предварительная проверка первого члена обеспечивает правильную пустую сумму.
- `lab.GoTo`: обычный граф с явной меткой `begin` и беззначным обратным
  переходом `end.repeat → begin.enter`; сравнение подаёт Boolean на развилку.

Отдельных текстовых ключевых слов `repeat`, `until`, `goto` в текущем профиле
нет. Последние два способа выражены непосредственно графами EMS. Если преподаватель
требует именно эти текстовые ключевые слова, это ограничение реализации следует
учесть: графовая эквивалентность не является заявлением о поддержке такой грамматики.

Нулевое, отрицательное и нечисловое ε дают ошибку, предыдущий результат сохраняется
транзакционным откатом. Действуют общие лимиты операций и времени исполнения;
для чрезвычайно малых ε возможна ошибка бюджета. Проверенные значения: 1,
0.8333333333333333, 0.5, 0.001, 0.000001; отрицательные/нулевые/нечисловые входы.

Графовый вход открыт кнопкой «Контракты и графы лабораторной № 2» на странице
проектов. Переход открывает общий контрактный модуль, откуда граф любой операции
Series загружается вместе с библиотекой контрактов. Причина прежнего пустого экрана
была в `lab.Validate`: его строковый `throw` поднимал модуль в профиль
`ems-control-errors/1`, который проекция не принимала. Строковая ошибка теперь
представлена терминальным атомом `std.error.Throw` с сохранением ошибки `USER_THROW`.
Обычная проекция явно отклоняет выброс нестрокового значения, а не теряет его.
Реальная браузерная проверка открывает `series::While`, проверяет библиотеку
арифметических контрактов и открывает `lab.Validate` как обычный редактируемый граф.
Графовые представления `While` и `For` строятся проекцией из того же EMS-исходника;
`RepeatUntil` и `GoTo` сохраняют authored-графы. Это исправляет открытие и редактуру,
но само по себе не утверждает, что все четыре реализации уже имеют одинаковую
структуру графа.

Проверки: `tests/lab6.test.mjs` сравнивает все способы с независимой формулой,
проверяет строгую границу/откат, соответствие исходника сохранённому проекту и
скомпилированное приложение в новом Node-процессе. Browser acceptance проверяет
реальный UI Worker и скачанный самостоятельный DOM-пакет после выключения EMS
origin. Наличие четырёх вычислительных способов не объявляет завершённой всю
языковую грамматику или глобальную цель EMS.

Пересборка проверенного документа из исходника:

```sh
node tools/ems.mjs application-project examples/lab6.ems --out examples/lab6.ems-project.json
```
