# EMS-039 — мобильное рабочее пространство и PWA

Указание владельца 2026-10-15: красивый мобильный интерфейс, PWA,
отключение HTTP Basic Auth. Это явное разрешение публичного dev-доступа.

Дизайн: инженерный холст остаётся главным экраном; спокойная светлая рабочая
область, тёмная нижняя панель инструментов, синий акцент выбранных действий.
Палитра: canvas #f3f6fb, chrome #17263d, ink #1c2940, accent #4167e8,
line #dce3ed. Системный шрифт без внешних запросов, крупные цели касания.
На телефоне инструменты открываются снизу; desktop сохраняет перемещаемые окна.
Прочитан и применён frontend-design:
https://github.com/anthropics/skills/tree/main/skills/frontend-design
Скилл не запускает модели или агентов; ограничения Sol/Luna сохраняются.

## AC-101

- На390px нет горизонтального переполнения; холст занимает рабочее пространство,
  undo/redo/fit/масштаб и нижняя панель доступны пальцем.
- Библиотека/свойства/результат открываются по требованию. UI-инструменты показывают
  одно окно; элементы и контракты добавляются touch-перетаскиванием.
- Сенсорная панорама и pinch меняют камеру, не семантику программы.
- Обычный контракт «Число» редактируется на карточке; недопустимое значение отклоняется;
  сохранённая программа без внешних входов возвращает4.
- Manifest проверяется Chromium; локальные PNG192/512, standalone display,
  scope/start_url, установка через браузер или beforeinstallprompt.
- Service worker кэширует проверяемый снимок ресурсов проекта. После отключения
  сети и перезагрузки граф возвращает5, UI-счётчик1 через настоящий Worker.
- HTTP Basic Auth отсутствует в текущем nginx-конфиге и deploy pipeline;
  анонимный HTTPS GET200, служебные пути403, POST405, HTTP→HTTPS сохраняется.
- Полный Node/verify/Chromium gate и публичные HTTPS/mobile/PWA проверки проходят.

## Обновления и границы

`node tools/build-offline-assets.mjs` обновляет snapshot/hash после изменений
web/src/examples. Проверка `tests/pwa.test.mjs` отклоняет устаревший снимок.
Service worker имеет scope `/` через специальный response header; кэширует только
перечисленные same-origin GET, не перехватывает private/служебные пути и POST.
Кэш включает исходники/примеры, в том числе .ems. Пользовательские проекты остаются
в localStorage устройства, в shell cache не записываются.

Новая версия получает отдельный cache; ожидающий worker активируется кнопкой
«Обновить» с предупреждением сохранить изменения. Смена worker перезагружает UI.
На первой загрузке нужна сеть и завершённая установка worker. Наличие manifest
не доказывает ручную установку на физическом iPhone/Android; их системные диалоги
зависят от браузера. Офлайн-исполнение не добавляет native backend и не делает
доступными отсутствующие сетевые контракты.

Публичный dev-сайт распространяет клиентские исходники и примеры; сервер остаётся
статическим, проекты и их бизнес-состояние не отправляются на сервер. Старый файл
приватного доступа не публикуется и больше не используется deployment/smoke.

Уточнение владельца: новые элементы не обособляются. Один компонент `literalEditor` редактирует литеральные входы всех контрактов на холсте и в свойствах; «Число» использует существующий `std.value.Number`, без нового node kind, формата, Runtime или специальной ветки по ID. Подтверждающий сценарий: те же поля для `core.add(a=2,b=3)` дают5, значение контракта «Число» даёт4.
