# ADR-0015 — текущий текст статического native модуля

Статус: принято для finite synchronous профиля AC-130.

## Контекст

Semantic module хранит интерфейс определения, поля и инварианты отдельно от
привязанных тел операций экземпляров. После графовых правок эти тела могут
отличаться. Архив исходника сохраняет историю создания и не описывает текущую
реализацию. Для развития G-01/G-02/G-03 нужен исполняемый текст из текущего IR.

## Решение

Общий EMS parser поддерживает interface operation с `;` и явные ссылки на
контракты реализации, инициализации и инвариантов. Привязка определяет entry
существующего IR2. Проверяется интерфейс: имена и типы портов, выход и разрешённая
чистота. Инстанцирование интерфейса без реализации — ошибка.

Logical state calls разрешаются существующим native linker в genuine kernel
атомы. Начальные программы и predicates проверяются с pure registry и своим
транзитивным замыканием. Печать и проверка текста не исполняют эти программы.

Публичный named dispatch связывается с реализацией непосредственно. Для текстового
позиционного вызова интерфейса с другим порядком параметров реализации создаётся
обычный IR adapter. Сначала вычисляются аргументы интерфейса слева направо; adapter
переставляет только полученные значения. Его frame и работа входят в общие лимиты.
Перестановка самих выражений аргументов недопустима из-за порядка эффектов/ошибок.

Source backend печатает finite control constructs из IR, гигиенически нормализует
внутренние имена и повторно проверяет текст общим linker. Type ascriptions снимаются
при lowering. Атомарные signed/NumberArray literal формы сохраняют существующие
literal nodes и их work accounting. Новых runtime opcodes или evaluator нет.

## Следствия и следующий gate

Текущая программа, включая изменённые тела экземпляров и UI, может экспортироваться
в EMS, редактироваться, импортироваться копией и собираться прежним standalone
compiler. Текст нормальной формы может содержать activation state machine.
Внутренние ID/locations и исходное форматирование не являются гарантией экспорта.

Layout и сохранённые графовые witnesses принадлежат документу редактора. Применение
полного текста к исходному документу требует отдельного согласованного обновления
semantic IR, идентичности узлов/графов, geometry, incomplete drafts и CAS. AC-130
этот следующий gate не закрывает. Глобальная цель и общий inverse остаются активными.
